# E0 Legacy Archive

This folder contains old E0 helper scripts, split-generation utilities, notes, and generated preprocessing artifacts that are not part of the active E0 training path.

Active E0 code uses:

```text
e0_image_only/config.py
e0_image_only/learning/
e0_image_only/model/
G:\FOR THESIS\MAIN\Data
```

The archived `preprocessed_224/` tree contains generated `_224.jpg` files moved out of root `Data` so the shared dataset remains raw.
