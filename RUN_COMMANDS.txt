======REGENERATE FROM SCRATCH (full pipeline order)=====

Data\ (train/val/test.csv + per-sample image+IoT folders) must be present.
Run in order; each step's outputs feed the next.

1. E1 IoT features  ->  & ".\.venv-e1\Scripts\python.exe" e1_iot_only\scripts\extract_iot_features.py
2. E0 train         ->  .\scripts\thesis.ps1 -Action e0
3. E1 train         ->  .\scripts\thesis.ps1 -Action e1
4. E2 extract       ->  .\scripts\thesis.ps1 -Action e2-extract
5. E2 train         ->  .\scripts\thesis.ps1 -Action e2-train
6. E3 smoke         ->  & ".\.venv-e1\Scripts\python.exe" .\e3_quantum_fusion\scripts\smoke_test.py
7. E3 E2-matched    ->  see e3_quantum_fusion\RUN_COMMANDS.txt
8. E3-4 VQC         ->  see e3_quantum_fusion\RUN_COMMANDS.txt

The step 1 feature CSVs already exist (e1_iot_only\features\{train,test}_iot_features.csv);
only re-run step 1 if Data changes.

======E3=====

Full E3 command list:

e3_quantum_fusion\RUN_COMMANDS.txt

Smoke test:

& ".\.venv-e1\Scripts\python.exe" .\e3_quantum_fusion\scripts\smoke_test.py

Train E2-matched-4:

& ".\.venv-e1\Scripts\python.exe" .\e3_quantum_fusion\scripts\train_e3.py `
  --model e2_matched `
  --run-name e2_matched_4 `
  --batch-size 512 `
  --epochs 60 `
  --patience 8 `
  --lr 0.001 `
  --weight-decay 0.0001

Train E3-4 VQC:

& ".\.venv-e1\Scripts\python.exe" .\e3_quantum_fusion\scripts\train_e3.py `
  --model e3_4 `
  --run-name e3_4_vqc `
  --sim lightning.qubit `
  --batch-size 512 `
  --epochs 60 `
  --patience 8 `
  --lr 0.001 `
  --weight-decay 0.0001

E3-4 runs on CPU with lightning.qubit in this environment because lightning.gpu
is not installed. E2-matched-4 uses CUDA when available.
