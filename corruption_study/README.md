# Corruption Robustness Study

This folder contains the P2 corruption-robustness harness. The study evaluates whether
multimodal fusion degrades more gracefully than unimodal models when only the test data is
corrupted.

No model is retrained or fine-tuned in the primary study. Train and validation data remain clean.
All corruptions are materialized once to disk and reused by the relevant models.

## Models

Core comparison:

```text
E0 image-only vs E2-canonical/E2-8 under image corruption
E1 IoT-only vs E2-canonical/E2-8 under IoT corruption
E2-canonical vs E2-8 under representative paired stress
```

Exploratory variant:

```text
e2_128_25
```

`e2_128_25` is a practical exploratory classical fusion variant. It is not part of the core
controlled comparison and is not a parameter-matched E3 comparator.

## Severity Scope

```text
clean sanity severity: 0
primary corrupted severities: 2, 3, 5
deferred if time allows: 1
not currently defined: 6
```

Severity 6 requires explicit new schedules before use.

## Image Corruptions

Images are loaded as RGB, resized to `224 x 224` with bilinear interpolation, corrupted at that
model-input geometry, and saved as PNG. The corrupted-image eval path applies no further geometric
resize if the PNG is already `224 x 224`; it only normalizes for the model.

Corruption schedules:

```text
gaussian_noise std:           [.08, .12, .18, .26, .38]
motion_blur (radius, sigma):  [(10,3), (15,5), (15,8), (15,12), (20,15)]
defocus_blur (radius, alias): [(3,.1), (4,.5), (6,.5), (8,.5), (10,.5)]
brightness_increase delta:    [.1, .2, .3, .4, .5]
brightness_decrease delta:    [-.1, -.2, -.3, -.4, -.5]
contrast factor:              [.4, .3, .2, .1, .05]
jpeg_compression quality:     [25, 18, 15, 10, 7]
```

`jpeg_compression` is encoded and decoded in memory, then saved as PNG to avoid adding a second
JPEG artifact from the output format.

## IoT Corruptions

IoT corruption is feature-space corruption over extracted continuous summary features, not raw
time-series device corruption. This matches the E1/E2 model input space. Metadata columns are left
unchanged:

```text
image, label, crop, disease, stage, n_rows
```

Corruption schedules:

```text
sensor_noise: Gaussian noise std = [.1, .2, .3, .5, 1.0] x train feature SD
dropout:      per-cell null fraction = [.05, .10, .20, .30, .40], imputed with train feature mean
drift:        signed offset = [.25, .5, 1.0, 1.5, 2.0] x train feature SD
```

Means and standard deviations are computed from the training split only. Validation/test statistics
are not used for scaling, imputation, or corruption.

The exact corrupted columns are saved in:

```text
corruption_study/results/corrupted_iot_columns.json
```

## E2 Embedding Regeneration

E2 models do not consume raw images or raw IoT CSVs at evaluation time. They consume cached
embeddings:

```text
image embedding: 1280 dims
IoT embedding:     64 dims
fusion input:    1344 dims
```

For every corrupted E2/E2-8/e2_128_25 condition, embeddings are regenerated by passing the
corrupted test inputs through the frozen E0/E1 encoders:

```text
corrupted image -> frozen E0 encoder -> fresh image embedding
corrupted IoT   -> frozen E1 encoder -> fresh IoT embedding
concat          -> E2 variant prediction
```

Cached clean embeddings are never corrupted directly.

Clean regenerated embeddings are checked through `clean_regen`. For E2 variants, regenerated-input
conditions use `clean_regen` as the clean reference for point-estimate drops and paired bootstrap
drop CIs. E0/E1 use severity-0 `clean`.

## Sanity Checks

Severity 0 evaluates the original clean test inputs and must reproduce audited clean metrics.

Passthrough materializes resized PNGs with no corruption and verifies the resized-PNG image path.
Passthrough tolerance is `0.005` absolute delta for accuracy and Macro-F1.

Generated sanity reports:

```text
corruption_study/results/severity0_sanity_check.md
corruption_study/results/passthrough_sanity_check.md
```

## Representative Paired Stress Conditions

Paired stress conditions use matched severity index only:

```text
image severity k + IoT severity k
```

This is not calibrated-equivalent damage across modalities. Reports call these
`representative paired stress conditions`.

Completed paired stress conditions:

```text
canonical:                         gaussian_noise + sensor_noise
data-driven worst-case distinct:   defocus_blur + drift
```

The worst-case distinct pair was selected from completed single-modality results:

```text
E0 worst image corruption mean Macro-F1 drop: defocus_blur = 0.903679
E1 worst IoT corruption mean Macro-F1 drop:   drift        = 0.821596
```

This pair is distinct from `gaussian_noise + sensor_noise`, so no fallback to the second-largest
IoT corruption was needed.

## Bootstrap Confidence Intervals

Bootstrap CIs are computed offline from saved prediction CSVs. No inference is rerun.

Settings:

```text
resamples: 1000
CI:        95% percentile interval
seed:      20260609
macro-F1:  present-class macro-F1; labels absent from a resample are skipped
```

Absolute metric CIs resample the condition predictions. Drop CIs use paired bootstrap: clean and
corrupted predictions are aligned by `sample_id`, and the same bootstrap indices are applied to
both before computing the drop.

CI fields:

```text
accuracy_ci_low, accuracy_ci_high
macro_f1_ci_low, macro_f1_ci_high
accuracy_drop_ci_low, accuracy_drop_ci_high
macro_f1_drop_ci_low, macro_f1_drop_ci_high
```

Settings are saved in:

```text
corruption_study/results/bootstrap_settings.json
```

## Interpretation

The main robustness evidence is Macro-F1 degradation from the correct clean reference, not clean
accuracy alone:

```text
Macro-F1 drop = clean Macro-F1 - corrupted Macro-F1
```

The thesis claim is supported when E2-canonical and/or E2-8 show smaller Macro-F1 drops than the
matching unimodal baseline under the same corrupted modality.

The difference-of-drops bootstrap directly estimates:

```text
unimodal Macro-F1 drop - multimodal Macro-F1 drop
```

Positive values mean the multimodal model degraded less than the matching unimodal baseline.
